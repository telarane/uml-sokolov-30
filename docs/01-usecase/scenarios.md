## ВИ-01. Заказать поездку (самый ценный для бизнеса)

**Актеры:** клиент (первичный), водитель, платёжный шлюз, картографический сервис

**Цель:** оформить заказ такси с расчётом стоимости и подбором водителя

**Предусловия:** клиент авторизован; указаны адрес подачи и адрес назначения; аккаунт не заблокирован

**Постусловия (успех):** создан заказ; назначен водитель; сумма зарезервирована на платёжном шлюзе

**Постусловия (неуспех):** заказ не создан; резерв не удержан

**Связи:** include ВИ-06 «Проверить статус клиента»; extend ВИ-07 «Рассчитать цену», ВИ-08 «Подобрать водителя»

### Основной сценарий

| # | Действие актера | Отклик системы |
|---|---|---|
| 1 | Клиент указывает адрес подачи и адрес назначения | |
| 2 | | Система запрашивает у картографического сервиса координаты и расстояние |
| 3 | | Система рассчитывает стоимость поездки с учётом тарифа и коэффициента спроса |
| 4 | Клиент подтверждает заказ | |
| 5 | | Система проверяет статус клиента: нет долгов и блокировок |
| 6 | | Система подбирает свободного водителя в радиусе 5 км |
| 7 | | Система резервирует сумму на платёжном шлюзе |
| 8 | | Система уведомляет клиента: «Водитель назначен» |
| 9 | Клиент ожидает подачу автомобиля | |
| 10 | | Система передает заказ водителю |

### Исключения

**И-1. Клиент отказался от заказа** (шаг 4)
Система не создает заказ и завершает сценарий. Состояние системы не изменяется.

**И-2. Клиент заблокирован или имеет долг** (шаг 5)
Система показывает причину блокировки и предлагает обратиться в поддержку. Заказ не создается. Возврат к шагу 1 либо завершение.

**И-3. Свободных водителей нет** (шаг 6)
Система расширяет радиус поиска до 10 км. Если водителей нет и там — предлагает клиенту подождать или отменить заказ. Если клиент ждет — повтор поиска каждые 30 секунд.

**И-4. Водитель не принял заказ** (шаг 10)
Прошло 30 секунд — ответа нет. Система блокирует водителя на 5 минут и ищет следующего. Если все водители проигнорировали — возврат к И-3.

**И-5. Платёжный шлюз недоступен** (шаг 7)
Система отменяет заказ и уведомляет клиента о технической ошибке. Резерв не удержан. Возврат к шагу 1.

### Примечания

Коэффициент спроса рассчитывается отдельным сервисом динамического ценообразования (см. доменную модель, часть 3).
При высоком спросе коэффициент может достигать ×2.0.
