1. Служба такси – это информационная система для заказа поездок, подбора водителей и динамического ценообразования.
2. 
3. Клиент указывает адрес подачи и адрес назначения, система рассчитывает стоимость с учётом текущего спроса и подбирает ближайшего свободного водителя.
4. Водитель получает предложение, принимает заказ и выполняет поездку, а по завершении обе стороны могут оставить отзыв и оценку.
5. Оплата проводится через внешний платёжный шлюз, а маршрут и расстояние рассчитываются через картографический сервис.
6. Система поддерживает отмену поездки с автоматическим расчётом штрафа в зависимости от статуса заказа.
7. Диспетчер может разрешать спорные ситуации между клиентом и водителем.
